# Workspace Rule: Auto-Push to GitHub

Whenever you make any updates, changes, bug fixes, or feature additions in this repository:
1. Verify the code compiles and works cleanly.
2. Stage all changed and new assets/code (`git add <files>`).
3. Commit with a clear, descriptive message (`git commit -m "..."`).
4. Immediately push to GitHub (`git push origin main`) without waiting for the user to request it.
5. Confirm the commit hash and push status in your response to the user.
