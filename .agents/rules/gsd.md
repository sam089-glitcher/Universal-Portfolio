# Workspace Rule: Get Shit Done (GSD) Protocol

## Purpose
Spec-driven execution framework designed to maximize engineering throughput and eliminate context rot.

## Principles
1. **Spec-Driven Planning:** Before taking action, decompose goals into clear, verifiable phases and concrete tasks.
2. **Context Isolation:** Keep working memory focused on the active task. Avoid loading unnecessary files.
3. **Atomic Milestones:** Complete each task end-to-end, verify against durable state (filesystem, compiler, tests), and confirm completion before advancing.
4. **Zero Fluff:** Provide crisp, direct progress updates with clear status indicators (DONE, IN-PROGRESS, BLOCKED).
